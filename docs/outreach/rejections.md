# Outreach Rejection Log

Record of prospects who declined Valence outreach or asked to stop being contacted.

**This file is the do-not-contact list.** Check it before adding anyone to an outreach
sequence. Under CASL (Canada's Anti-Spam Legislation), an opt-out request must be honoured
within 10 business days and applies indefinitely — there is no re-engagement window for
anyone marked `Hard opt-out`.

## How to use

1. When a prospect declines or asks to stop, add a row to the table below and a detail
   entry under [Entries](#entries) on the same day.
2. Suppress the address in whatever tool sent the outreach — logging it here does not
   remove it from a live sequence.
3. Never delete rows. If a contact later opts back in, add a new row noting the consent
   rather than editing the original.

### Rejection types

| Type | Meaning | Re-contact |
| --- | --- | --- |
| `Hard opt-out` | Explicit stop/unsubscribe request | Never |
| `Not interested` | Declined the offer, no opt-out language | Not before 12 months, and only with a new reason to reach out |
| `Bad timing` | Interested in principle, wrong moment | At the date the prospect gave |
| `Wrong fit` | Out of ICP (portfolio too small, wrong sector, etc.) | Only if their situation materially changes |
| `No authority` | Not the decision maker | Contact the referred person instead, not this one |
